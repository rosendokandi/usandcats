## 🌟 项目简介

**Us & Cats** 专为情侣打造，融合了 8-bit 复古像素美学（Pixel Retro）与温润柔和的莫兰迪/马卡龙配色（Morandi Pastel）。它由四大核心场景组成：
1. **🏠 首页（甜蜜空间）**：恋爱天数实时计算、拍立得主图相框、会说话且可抚摸互动的像素猫咪 Mochi。
2. **📖 我们的故事（浪漫时间轴）**：记录从相遇到未来的每个里程碑节点，支持分类筛选、点赞与新增。
3. **📸 甜蜜瞬间（像素影像馆）**：拍立得照片墙（瀑布流排版）、斜切彩色胶带、全屏大图灯箱浏览。
4. **💌 小情书（治愈留言板）**：彩色便签墙、6 种心情图标、发帖身份切换、留言置顶、点赞与删除。
5. **⚙️ 空间个性化设置**：自定义恋爱起始日、双方昵称、猫咪名字、更换情侣头像、8-bit 音效开关与深浅色模式。

## 🛠️ 技术栈与架构设计

### 核心技术选型
| 模块 / 层次 | 选用技术 | 说明与优势 |
| :--- | :--- | :--- |
| **前端框架** | **React 18.3** | 函数式组件化、Hooks 状态流管理 |

## 📐 项目规范与编码约定

### 1. 代码架构规范
- **单一职责**：视图页面（`pages`）只负责组合展示；业务逻辑与数据存储统一封装在 `AppContext` 中。
- **类型安全**：所有数据实体（`Milestone`, `Memory`, `LoveNote`, `UserSettings`）必须在 `src/types/index.ts` 中显式定义，禁止使用 `any`。
- **无无用引入**：遵循 TypeScript 严格模式，禁止存在未使用的变量或未使用的 `import`。

### 2. 视觉与 UI 像素设计规范
- **像素边框规范**：
  - 常规边框：`border: 4px solid #574144` (`.pixel-border`)
  - 轻量边框：`border: 2px solid #574144` (`.pixel-border-sm`)
- **像素交互阴影规范**：
  - 常规态：`box-shadow: 4px 4px 0px 0px #574144`
  - 悬停态：`transform: translate(-2px, -2px); box-shadow: 6px 6px 0px 0px #574144;`
  - 按下态：`transform: translate(4px, 4px); box-shadow: 0px 0px 0px 0px #574144;`
- **配色语义**：
  - `primary` (`#70585b`): 暖栗棕（主品牌色、主要按钮）
  - `primary-container` (`#fadadd`): 蜜桃粉（高亮底色、爱心、粉色便签）
  - `tertiary-container` (`#d6e6d7`): 抹茶绿（薄荷绿便签与胶带）
  - `secondary-container` (`#e1e1f5`): 薰衣草紫（紫色便签与胶带）
  - `pixel-outline` (`#574144`): 像素描边与文字暗色

## 💡 Git 实用操作与回退教程

本项目当前已被 Git 完整管理。以下是针对日常开发和**万一改错代码如何安全回退**的保姆级指南：

### 1. ⚠️ 万一改错代码，如何回退到当前版本（`v1.0.0`）？

#### 情况 A：刚刚改了代码但还没提交（想彻底放弃当前所有未保存修改）
```bash
# 撤销所有工作区文件的修改，恢复到上一次提交的状态
git restore .

# 如果新增了临时文件，一并清理
git clean -fd
```

#### 情况 B：已经 commit 了代码，但想彻底回滚到 v1.0.0 初始版本
```bash
# 强制回滚到 v1.0.0 版本的状态（注意：v1.0.0 之后的所有修改会被重置）
git reset --hard v1.0.0
```

#### 情况 C：想保留当前修改，只是先看看 v1.0.0 原来的样子
```bash
# 把当前未完成的代码暂存到暂存区
git stash

# 切换回 v1.0.0 查看
git checkout v1.0.0

# 恢复之前暂存的工作
git checkout main
git stash pop
```
