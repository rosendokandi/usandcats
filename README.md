## 🌟 项目简介

**Us & Cats** 专为情侣打造，融合了 8-bit 复古像素美学（Pixel Retro）与温润柔和的莫兰迪/马卡龙配色（Morandi Pastel）。它由五大核心模块组成：
1. **🏠 首页（甜蜜空间）**：恋爱天数实时倒计时、拍立得主图相框、会说话且可抚摸互动的像素猫咪 Mochi。
2. **📖 我们的故事（浪漫时间轴）**：记录从相遇到未来的每个里程碑节点，支持分类筛选、点赞与新增。
3. **📸 甜蜜瞬间（像素影像馆）**：拍立得照片墙（瀑布流排版）、斜切彩色胶带、全屏大图灯箱浏览。
4. **💌 小情书（治愈留言板）**：彩色便签墙、6 种心情图标、发帖身份切换、留言置顶、点赞与删除。
5. **🚪 情侣专属秘密小屋（双人云端房间）**：基于 Stitch 设计的专属门禁，一人设密创建（生成如 `LOVE-520` 专属暗号），伴侣输入暗号即可秒进，双人多端实时推送同步！

## 🛠️ 技术架构与双模设计

```
   [👦 你的设备]             [👧 TA 的设备]
         │                         │
         └───► 🌐 Cloudflare Pages ◄┘ (前端托管：国内秒开、自动持续集成)
                     │
                     ▼
         🗄️ Supabase 实时云数据库 (Realtime WebSockets)
     ┌───────────────┴───────────────┐
     │ 房间加密隔离 (Rooms)            │
     │ 故事时间轴 (Milestones)        │
     │ 拍立得相册 (Memories)          │
     │ 小情书留言 (Love Notes)        │
     └───────────────────────────────┘
```

- **双模自动兼容**：
  - **离线单机模式**：未加入房间时，所有数据完整保存在浏览器本地 LocalStorage，零网络依赖。
  - **云端房间模式**：输入房间暗号与密码后，自动从云端拉取共享回忆，并开启 WebSocket 实时通道。一方发送小情书或上传照片，另一方屏幕无需刷新即时弹出浮动气泡并播放 8-bit 音效！

## 🔑 情侣专属房间模式使用指南

1. **创建房间**：
   - 点击导航栏上的 **「情侣房间」** 按钮；
   - 填写双方昵称、恋爱起始日、猫咪名字与 6 位私密密码；
   - 点击「✨ 立即生成专属房间暗号」，生成如 `LOVE-520` 的专属票据；
   - 点击「📋 一键复制邀请发给 TA」。
2. **伴侣加入房间**：
   - 伴侣在 TA 的手机或电脑上打开网站；
   - 点击「情侣房间」➔ 切换到「🔑 输入暗号回家」；
   - 输入房间暗号（如 `LOVE-520`）和密码，点击开门，即可成功同步所有回忆！

## 🗄️ Supabase 数据库一键初始化

为了在您的 Supabase 中开启完整的房间表结构与 Realtime 实时同步，只需在 Supabase 中运行一次初始化脚本：

1. 登录 [Supabase 控制台](https://supabase.com/dashboard) 进入您的项目；
2. 点击左侧菜单栏的 **`SQL Editor`**（图标为 `>_` SQL 终端）；
3. 点击 **`+ New Query`**，将项目根目录下的 [`supabase_schema.sql`](file:///c:/D/Code/q/supabase_schema.sql) 文件内容全部复制粘贴进去；
4. 点击右下角的绿色 **`Run`** 按钮执行即可！

## 🌐 Cloudflare Pages 免费极速部署

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)；
2. 点击左侧 **Workers & Pages** ➔ **Create application** ➔ **Pages** ➔ **Connect to Git**；
3. 选择您的 GitHub 仓库 **`rosendokandi/usandcats`**；
4. 构建配置如下：
   - **Framework preset**：`Vite`
   - **Build command**：`npm run build`
   - **Build output directory**：`dist`
5. 点击 **Save and Deploy**，约 15 秒后即可获得全球 CDN 加速的公网专属网址！
